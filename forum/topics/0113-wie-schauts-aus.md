## 4. pcsquirrel · 14. Mär 2008, 20:00

Hi,

irgendwie würde ich mich auch gerne ein wenig an der weiterentwicklung von betty beteiligen.

Wer arbeitet denn im moment so an boop. so weit ich dem SVN Log entnehmen kann stammt BOOP von mamalala und wurde von telekatz um die RF Geschichten erweitert.

In welche Richtung soll die Entwicklung gehen? Gibt´s eine "Roadmap".

Meine Entwicklungsinteressen für Boop gehen jetzt primär natürlich in Richtung Universal-FB. Eigentlich so wie weit BOOP jetzt ist. Ich wmöchte es als nächstes um "Punch-through" Funktionen erweitern. Bzw. ein wenig in richtung der Logitech FB´s. Sozusagen einen "tätigkeit" wählen. z.B.:

"DVD schauen" - Lautstärke und ein paar Tasten auf Fernseher, Rest der Tasten auf DVD-Player.
"Fernsehen" - Lautstärke und ein paar Tasten auf Fernseher, Rest der Tasten auf Sat-Receiver.

Kurz zusammengefasst die Tasten A-D wählen ein Schema und in einem Schema können jeder Taste eine Taste eines Fernbedienungs-Codes zuordnen. In einem Schema auch Codes verschiedener Fernbedienungen.

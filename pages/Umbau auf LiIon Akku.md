# Umbau auf LiIon Akku

Hier wird bald beschrieben, wie man die [Betty](Betty.md "Betty") statt mit 2x NiMH Akkus mit einem LiIon Akku betreiben kann. Daraus resultiert eine längere Laufzeit.

Dazu muss man einen zusätzlichen DC-DC Wandler in die Betty einbauen + einen Laderegler in die [Ladestation](Ladestation.md "Ladestation").

  
Schonmal paar benötigte Teile:

MAX710 DC-DC Wandler (Step Up/Down)

MAX1811 Laderegler LiIon

\+ Paar teile drumrum.

Eine LED in der Ladestation wird dann den Ladezustand des Akkus anzeigen.

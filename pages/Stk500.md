# Stk500

When you own a atmel STK500 development board, you can flash your betty very easy!

  

### Board-Settings

[<img src="../images/4/42/Stk-settings.jpg" width="250" height="267" alt="Stk-settings" />](Datei_Stk-settings.jpg.md)

Settings

The target and reference-voltage should be set to 3.3V. This step is optional because the LPC2220 pins are 5V tolerant.

  

### Cable Connections

[<img src="../images/4/4e/Stk500.jpg" width="250" height="188" alt="Stk500" />](Datei_Stk500.jpg.md)

Connections

You must connect the RS232-Cable to RS232-Spare on the board.

|            |        |
|------------|--------|
| Betty      | STK500 |
| RXD        | RXD    |
| TXD        | TXD    |
| Reset      | SW1    |
| Bootloader | SW0    |
| GND        | GND    |

[<img src="../images/4/44/Betty-isp.JPG" width="250" height="180" alt="Betty-isp" />](Datei_Betty-isp.JPG.md)

Betty-ISP

### Software

You can use a flash-tool of your choice ;)
